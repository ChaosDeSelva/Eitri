# Changelog

## 0.1.0 (unreleased)

First public version.

- Plan an image set from an idea: style brief, shared prompt and one subject per image, streamed live.
- Import prompt lists from CSV or JSON, export and re-import specs.
- Providers: OpenAI (verified), Google Gemini and Imagen, fal.ai, Replicate, Stability AI, and any OpenAI-compatible endpoint.
- Batch runs with a worker pool: pause, resume, stop, concurrency, budget cap, stop on key, quota and billing errors.
- Pixel checks for transparent art and background keying for providers without native alpha.
- Style references, redo with a note as an edit or a fresh draw, keyboard review.
- Export square PNG masters and WebP copies atomically; reveal in the file manager.
- Duplicate projects, desktop notifications when a run ends, light and dark themes.
- Keys stored only in the OS keychain; no telemetry.
