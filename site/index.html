Why Eitri

Everything around the image call, done for you.

Making one image is easy. Making three hundred that match is not: you end up pasting prompts into a chat, downloading files by hand and losing track. Eitri handles the whole loop.

Idea to plan, live

A planning model writes a style brief, a shared prompt and one specific description per image, streamed in as it is written. Edit anything before you spend a cent.

One style, hundreds of images

Approved images become style references, rotated across the set, so a big batch stays consistent without collapsing onto one look.

Batch runs you control

Several images draw at once. Pause, resume, stop, change concurrency, and set a dollar cap per project. Every image shows its status and cost.

Pixel checks for transparent art

Solid backgrounds, see-through holes inside the subject and subjects sitting too small are caught automatically and retried once before they reach you.

Redo with a note

Write what to change and Eitri edits that exact image, or redraws it with your note. Review with the keyboard: A approve, R reject, F feedback.

Export for real projects

Square PNG masters at any size plus WebP copies, your own file names, written straight into the folder your game or site loads from.

How it works

From one sentence to a finished set.

Every step is resumable. Quit mid-run and the next run picks up exactly where it stopped.

Describe

"48 fantasy potion bottles for an inventory, chunky hand-painted, transparent." Or start from a base, or import a CSV of prompts.

Preview

Draw two or three. Keep the ones you like as style references for the rest.

Run

Approve the spec, press Run and watch the grid fill in, inside the budget you set.

Review and export

Approve, reject or redo with notes, then export the approved set to your art folder.

Base library

Keep the generic half of your prompts.

Good prompts for a set have two halves: a generic base that fixes the look, and a specific subject per image. Eitri keeps bases in a library you can reuse in any project.

  • Six built-in starters: portrait bust, mascot crest, item icon, pixel sprite, isometric tile, full-body character.
  • Generate a base from a description of the look.
  • Save any project's tuned style as a base, with its references.
  • Apply one and the planner only writes the subjects.
Specific · one per image
A tall emerald bottle with a cork stopper, glowing green liquid, a tiny silver leaf charm on a string.

Framing: one object centred at a slight three-quarter angle, filling about seventy percent of a square frame.
Style: hand-painted stylised game icon, chunky silhouette, saturated colours, a clean dark outline.
Canvas: 1024 by 1024 pixels.
Background: fully transparent.
No text, no letters, no logos, no watermarks.

Privacy

Your keys, your machine.

Eitri has no server and no account. You pay your provider directly, and nothing leaves your computer except the requests you make.

Keys in your keychain

Stored in macOS Keychain, Windows Credential Manager or Secret Service. Never in Eitri's database, logs or exports.

No telemetry

No analytics, no tracking, no update pings. The interface itself cannot reach the network.

Local data

Projects, prompts, images and every attempt's cost live in your app-data folder.

Install

Download, or build it yourself.

Grab a build from the releases page, or build from source with Rust, Node 22 and pnpm.

# build from source
git clone https://github.com/__OWNER__/eitri
cd eitri
pnpm install
pnpm tauri build   # app bundle in src-tauri/target/release/bundle

Make the whole set, not one image at a time.
